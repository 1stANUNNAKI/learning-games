# 🚀 رائد الفضاء الحسابي - Space Math Rider

لعبة تعليمية عربية للأطفال (6-9 سنوات) تعلم الحساب عبر اللعب

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/basharalameed/learning-games)

---

## 📖 الوصف

لعبة تعليمية تفاعلية مبنية بـ HTML5/Canvas تعلم الأطفال الجمع والطرح والضرب والقسمة والأشكال الهندسية وأنماط الأرقام من خلال مغامرة فضائية مشوقة.

### المميزات الرئيسية
- 🎮 5 مهارات حسابية (جمع وطرح، ضرب وقسمة، أرقام، أشكال، أنماط)
- 🎯 3 أساليب لعب (التقاط الفقاعات، التوصيل، الذاكرة)
- 🌍 5 كواكب استكشافية
- 👾 زعيم المجرة مع 10 مراحل
- ⏱️ وضع الاندفاع (60 ثانية)
- ♾️ تحدي لامتناهي بموجات متزايدة
- 📊 لوحة أبطال محلية
- 🔊 مؤثرات صوتية

---

## 🎮 طريقة اللعب

### التحكم
| الإجراء | لوحة المفاتيح | الماوس/لمس |
|---------|---------------|------------|
| التحرك | ← → أو W/A | اسحب على الشاشة |
| إطلاق الليزر | Space أو ↑ | زر "إطلاق" أو اضغط على الشاشة |
| إيقاف مؤقت | P أو Esc | - |
| كتم الصوت | M | زر الصوت |

### القواعد
1. اقرأ السؤال في أعلى الشاشة
2. التقط الفقاعة التي تحمل الإجابة الصحيحة بالصاروخ
3. أو استخدم الليزر لإصابة الإجابة الصحيحة
4. كل إجابة صحيحة = 10 نقاط + سلسلة نقاط (حتى ×3)
5. 3 قلوب = نهاية اللعبة
6. أكمل 10 أسئلة لتوصل الكوكب
